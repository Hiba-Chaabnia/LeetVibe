Step 4 — The Insight ▼

For each x we already know exactly what we need: target - x. Storing the values we have seen in a hash map turns the inner scan into an O(1) lookup, so a single pass is enough.

Step 5 — Optimize ▼
python
class Solution(object):
    def twoSum(self, nums, target):
        seen = {}
        for i, x in enumerate(nums):
            if target - x in seen:
                return [seen[target - x], i]
            seen[x] = i

Four ways to practice

Every session is a live conversation — ask follow-ups, push back, go deeper. The modes differ in one thing: how much help you want today.

LearnTeach me how to solve this

A strict 7-step workflow: brute force first, name its complexity, find the one key insight, write the optimal, measure the gain, and close with an algorithm mnemonic that makes the pattern stick.

Pair ProgrammingReview my attempt

You write first. LeetVibe runs your code, reports exactly what passed, diagnoses the precise lines, and nudges you with Socratic hints before revealing anything.

InterviewTest me for real

Alex, a senior engineer, runs a 30-minute mock technical interview — spoken aloud via ElevenLabs. He probes your complexity and edge cases, gives one hint, and never hands you the answer.

PracticeNo AI in the loop

Skip the agent entirely. Browse problems, write code, run tests, pull up hints, and read the built-in solution on your own. No API key required.

Beyond the modes

  • Problem browser — filter 2,800+ LeetCode problems by difficulty, topic, or solved status.
  • Inline code editor — write Python and run it against the real test cases without leaving the app.
  • Live test results — pass/fail per case, run in an isolated subprocess so an infinite loop times out instead of hanging.
  • Complexity analysis — the agent inspects the AST to gauge Big-O, then reasons about whether that estimate actually holds.
  • Statistics — session counts, solved-problem tracking, progress over time.
  • Cloud sync (optional) — sign in to persist progress across machines.

FAQ

What is LeetVibe?

LeetVibe is a free, open-source command-line application that turns LeetCode practice into a guided session with an AI coach. It runs entirely in your terminal: browse problems, write Python, run the real test cases, and have the agent teach, coach, or interview you.

Do I need an API key?

Only for the AI modes. LeetVibe uses your own Mistral API key for reasoning, and an optional ElevenLabs key for interview voice narration. Practice mode works with no keys at all.

What does it cost?

LeetVibe itself is free and MIT-licensed. You bring your own Mistral API key, and those requests are billed to your Mistral account according to your plan.

What leaves my machine?

Problem statements and code go to the Mistral API during sessions, and replies go to ElevenLabs if voice is enabled. Progress syncs to the cloud only if you create an account. Your API keys never leave ~/.leetvibe/.env.

Which terminals are supported?

Any modern terminal with truecolor support. On Windows, use Windows Terminal rather than legacy cmd.exe.

How do I update?

uv tool upgrade leetvibe or pip install -U leetvibe. LeetVibe also checks PyPI once a day and shows a toast when a newer version is available.
